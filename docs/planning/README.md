# docs/planning/

All HEIRLOOM planning and supervisor material. These documents define the
science and the decisions; the code in the rest of the repo implements them.

## Authority (highest first)
See `../decisions/AUTHORITY_AND_PROJECT_FILES.md`. In short:
latest supervisor instruction > proposals > decisions/manifest/plan >
Claude_Code_Plan.txt > frozen configs > run provenance > results > paper.

## Contents
- `Claude_Code_Plan.txt` — operational controller. **Read Section 0 first**
  (fresh-start summary + every frozen decision + build order).
- `HEIRLOOM_Research_Decisions.txt` — numbered decision log (D-01..D-53).
- `HEIRLOOM_Dataset_Manifest.txt` — datasets, models, triggers, rates.
- `HEIRLOOM_Experiment_Matrix.xlsx` — experiment/condition matrix.
- `HEIRLOOM_Project_Plan.txt` — phase/timeline plan.
- `HEIRLOOM_Feedback_Response.txt` — reply to supervisor feedback.
- `HEIRLOOM_Deep_Project_Analysis.txt` — pre-implementation analysis (S1-6).
- `README_PROJECT_FILES.txt` — original folder index (historical).
- `proposals/` — the two research proposals (internal master + professor).
- `supervisor/` — READ-ONLY originals: `heirloom.pdf`, `heirloom.tex`,
  `Project Mind Map.txt`, and the supervisor instruction file. Do not modify,
  rename or overwrite these; they are authoritative source material.
